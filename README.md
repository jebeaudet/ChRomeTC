# ChRomeTC
Chrome extension for RTC Nomade. Currently, the chrome only extension support french localization and chrome sync.

# How to install
Use the [Chrome web store](https://chrome.google.com/webstore/detail/chrometc/ghonlpiinhagjnhgiohnnbajakcfohid).

You can also clone this repo and add it via the developer mode in Chrome.

# FiReTC
This repo also host the Firefox version although it has not been updated with the most recent API change from the RTC so it's currently non functional. If you have an interest to revive it, just open an issue.
